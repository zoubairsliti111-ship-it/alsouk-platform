# ALSOUK UI Guidelines

## Design Principles
- Mobile-first
- Clean and modern
- Fast navigation
- Business focused

## Brand Colors
- Primary: #2563EB
- Success: #16A34A
- Background: #F8FAFC
- Text: #0F172A

## Typography
- Arabic RTL
- English/French LTR
- Clear readable fonts

## Components
- Buttons
- Cards
- Search Bar
- Category Cards
- Product Cards
- Supplier Cards
- Navigation
- Bottom Navigation
- Forms
- Modals

## UX Rules
- Maximum 3 taps to reach any feature
- Consistent spacing
- Responsive on all mobile sizes
- Accessible color contrast

## Vision
Build the easiest B2B marketplace in North Africa with a modern experience inspired by Alibaba and social discovery while keeping the interface simple.

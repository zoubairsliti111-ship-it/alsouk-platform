# Contributing to ALSOUK

## Goal
Build a modern, mobile-first B2B marketplace for North Africa.

## Development Rules
- Keep code clean and reusable.
- Follow the existing architecture.
- Avoid duplicate components.
- Prefer TypeScript.
- Test changes before pushing.

## Git Workflow
- Create a feature branch when needed.
- Write clear commit messages.
- Keep pull requests focused.
- Rebase before merging.

## UI Principles
- Mobile-first.
- Responsive.
- Fast loading.
- Accessible.
- RTL/LTR support.

## Documentation
Update documentation whenever architecture, database, deployment, or UI changes.

## Code Review Checklist
- No build errors.
- No TypeScript errors.
- Responsive design verified.
- Documentation updated if needed.
